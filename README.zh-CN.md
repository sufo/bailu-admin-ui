## 简介

[`bailu-admin-ui`](https://github.com/sufo/bailu-admin-ui) 是一个功能强大的后台管理前端项目，基于最新的前端技术栈，包括 **Vue3**, **Vite7**, **TypeScript**, **Pinia**, **UnoCSS** 和 **Naive UI**。

[后端项目](https://github.com/sufo/bailu-admin)。

## 特性

- **前沿技术应用**：采用 Vue3, Vite7, TypeScript, Pinia, UnoCSS 和 Naive UI 等最新流行的技术栈。
- **TypeScript**： 支持严格的类型检查，提高代码的可维护性。
- **现代化 UI 框架**：使用 Naive UI 提供高质量的组件库。
- **原子化 CSS**：集成 UnoCSS，实现高性能和灵活的样式开发。
- **丰富的主题配置**：内置多样的主题配置，与 UnoCSS 完美结合。
- **内置国际化方案**：轻松实现多语言支持。
- **灵活的权限路由**：同时支持前端静态路由和后端动态路由。
- **丰富的页面组件**：内置多样页面和组件，包括403、404、500页面，以及布局组件、标签组件、主题配置、表单、表格组件等。
- **移动端适配**：完美支持移动端，实现自适应布局。


## 使用

**环境准备**

确保你的环境满足以下要求：

- **git**: 你需要git来克隆和管理项目版本。
- **NodeJS**: >=18.12.0，推荐 18.19.0 或更高。
- **pnpm**: >= 8.7.0，推荐 8.14.0 或更高。

**克隆项目**

```bash
git clone https://github.com/sufo/bailu-admin-ui.git
```

**安装依赖**

```bash
pnpm i
```
> 本项目使用 pnpm 进行包管理。

**启动项目**

```bash
pnpm dev
```

**构建项目**

```bash
pnpm build
```
